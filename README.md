## 🎯 Learning Path

### For Frontend Developers
1. Start with [Frontend Fundamentals](./frontend/fundamentals.md)
2. Learn about [Component Architecture](./frontend/component-architecture.md)
3. Explore [State Management](./frontend/state-management.md) strategies
4. Understand [Application Structure](./frontend/app-structure.md)
5. Deep dive into [Performance Architecture](./frontend/performance.md)
6. Study [Design Patterns](./patterns/frontend-patterns.md)

### For Full-Stack Architects
1. Review [Architecture Principles](./fundamentals/principles.md)
2. Study [Architecture Patterns](./fundamentals/patterns.md)
3. Explore [System Design](./fundamentals/system-design.md)
4. Apply principles to [Frontend Architecture](./frontend/fundamentals.md)
